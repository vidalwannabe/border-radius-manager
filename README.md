# Border Radius Manager

GNOME Shell extension (GNOME 48) to customize the corner radius of shell elements: menus, calendar, notifications, dialogs, dash, Alt+Tab, app icons, search, and the quick settings menu (panel, toggles, header buttons, submenus, media player).

Every option starts at **-1 (system default)**, so nothing changes until you set a value. **0** gives square corners.

Works on its own or together with [Light Mode Manager](https://github.com/vidalwannabe/light-mode-manager).
