# Border Radius Manager

GNOME Shell extension (GNOME 48) to control rounded corners everywhere in the desktop.

- **Window corners** (tabs *General*, *Blacklist* and *Custom*): rounds application windows, with adjustable radius, smoothing, border, custom shadows, per-application overrides and an exclusion list.
- **Shell Elements** tab: corner radius of menus, calendar, notifications, dialogs, dash, Alt+Tab, app icons, search, and the quick settings menu (panel, toggles, header buttons, submenus, media player). Every option starts at **-1 (system default)**, so nothing changes until you set a value; **0** gives square corners.

Inspired by and built on [Rounded Window Corners Reborn](https://github.com/flexagoon/rounded-window-corners) by flexagoon, a fork of the original [Rounded Window Corners](https://github.com/yilozt/rounded-window-corners) by yilozt.
